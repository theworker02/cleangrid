# cleangrid

Clean validation gates for grid inputs before they hit prod.

**Site:** https://theworker02.github.io/cleangrid/

## Install / run

```bash
git clone https://github.com/theworker02/cleangrid.git
cd cleangrid
node src/cli.js
node --test
```
